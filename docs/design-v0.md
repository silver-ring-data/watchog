# Game News Auto Aggregator with Smart LLM Agent

게임 뉴스 및 게임 커뮤니티의 이슈 등을 자동으로 수집하고, LLM Agent를 활용하여 지능형으로 분류 및 처리한 후 카카오톡을 통해 통합 알림을 무료로 제공하는 시스템입니다.
* 주의사항 : 개인 PC 용이며, PC 스펙은 기술 스택 부분 참고

## 1. 프로젝트 개요

### 주요 기능
- **다중 소스 자동 수집**: 공식 사이트, 인벤, 디시인사이드, 게임 뉴스 포털 등으로부터 실시간 뉴스 크롤링
- **일정 자동 추출**: LLM Agent를 통한 패치, 이벤트 날짜 자동 파악
- **Google Calendar 동기화**: 일정이 있는 뉴스는 Google Calendar에 자동 등록
- **카카오톡 통합 알림**: 모든 뉴스와 일정 정보를 카카오톡으로 실시간 수신 (MCP 기반)
- **효율적 비용 관리**: 조건부 Agent 실행으로 LLM API 호출 최소화

### 지원 게임
로스트아크, 메이플스토리, 모비노기, 롤, 롤체, 포켓몬, 파이어엠블렘, 젤다의 전설, 도깨비, GTA 시리즈, 동물의 숲, 슈퍼마리오 시리즈, 팰월드, 지그문트 시리즈 등
* 개인적으로 주요하게 관심있는 게임만 선택하였고, 추후 확장 예정

### 데이터 소스
| 소스 | 수집 방식 | 난이도 | 비고 |
|------|---------|--------|------|
| 공식 사이트 | 규칙 기반 경량 크롤러 | 낮음 | 신뢰도 최상 |
| 인벤 | BeautifulSoup | 중하 | 게임 정보 풍부 |
| 디시인사이드 | Playwright | 중 | 핫이슈 감지 우수 |
| 게임 뉴스 포털 | API/RSS | 낮음 | 신뢰도 높음 |

### 미지원 소스
**에펨코리아**는 다음의 기술적 제약으로 인해 자동 크롤링이 불가능합니다:
- 완전 동적 콘텐츠 렌더링 (JavaScript)
- 정교한 봇 탐지 시스템 (Cloudflare)
- 엄격한 사용자 개인정보 보호 정책

대신 인벤, 디시인사이드, 게임 뉴스 포털을 통해 충분한 핫이슈 수집이 가능합니다.

## 2. 시스템 아키텍처

### 2.1 전체 흐름도

```
┌─────────────────────────────────────────────────────────┐
│  1단계: 게임 등록 및 규칙 학습 (초기 1회)                │
│  ────────────────────────────────────                  │
│  유저가 게임 선택 → AI Agent가 공식 사이트 분석          │
│  → 크롤링 규칙 자동 추출 → DB 저장                       │
└──────────────────┬──────────────────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────────────────┐
│  2단계: 정기적 멀티소스 크롤링 (자동 반복)              │
│  ────────────────────────────────────                  │
│  스케줄러 작동 (1시간 주기) →                            │
│  ├─ 공식 사이트: 저장된 규칙으로 빠른 수집               │
│  ├─ 인벤: BeautifulSoup 파싱                          │
│  ├─ 디시: Playwright JS 렌더링                        │
│  └─ 뉴스 포털: 직접 수집                                │
└──────────────────┬──────────────────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────────────────┐
│  3단계: 필수 LLM Agent 파이프라인                       │
│  ────────────────────────────────────                  │
│  ├─ [분류 Agent] 뉴스 분류 및 일정 여부 판단            │
│  │  결과: category + has_schedule (True/False)        │
│  ├─ [요약 Agent] 3줄 요약 생성                         │
│  ├─ [통합 Agent] 중복 이슈 통합                        │
│  └─ [감정 Agent (선택)] 커뮤니티 반응 분석              │
└──────────────────┬──────────────────────────────────────┘
                   │
        ┌──────────┴──────────┐
        │                     │
       YES                    NO
   (일정 있음)            (일정 없음)
        │                     │
        ▼                     ▼
┌──────────────────┐  ┌──────────────────┐
│  패치/이벤트     │  │   일반 소식      │
│ (일정 있는 뉴스) │  │ (이슈/성명/반응) │
└────────┬─────────┘  └────────┬─────────┘
         │                     │
         ▼                     ▼
┌──────────────────────────────────────┐
│  4단계: 조건부 일정 Agent 실행       │
│  ────────────────────────────────    │
│  [일정 Agent]만 실행 (has_schedule=  │
│   True인 뉴스에 대해서만)            │
│  ├─ 텍스트에서 날짜 추출             │
│  ├─ 시작/종료일 설정                 │
│  └─ ISO 8601 형식 변환               │
└────────┬──────────────────────────────┘
         │
         ▼
┌──────────────────────────────────────┐
│  5단계: 최종 목적지 분기             │
└────────┬──────────────┬──────────────┘
         │              │
         ▼              ▼
    ┌────────┐    ┌──────────────┐
    │Calendar│    │카카오톡 알림  │
    │API     │    │(MCP 기반)    │
    └────────┘    └──────────────┘
         │              │
         ▼              ▼
    ┌─────────────────────────────┐
    │  사용자 최종 수신            │
    │  - Google Calendar: 일정    │
    │  - 카톡: 모든 뉴스 + 일정    │
    └─────────────────────────────┘
```

### 2.2 데이터 흐름

```

         │
         ▼
    중복 제거 (해시 기반)
         │
         ▼
    필수 Agent 파이프라인
    ├─ 분류 Agent → category + has_schedule 판단
    ├─ 요약 Agent → 3줄 요약 생성
    └─ 통합 Agent → 멀티소스 이슈 통합
         │
         ▼
    DB 저장 (news, classified_news)
         │
    ┌────┴────┐
    │          │
   YES        NO
    │          │
    ▼          ▼
일정 Agent   직접 카톡 발송
    │          │
    ▼          ▼
Google Calendar + 카톡
```

# 기술 스택 및 시스템 요구사항

## 1. 환경 정보

### 개발 환경
- **OS**: Windows / Mac / Linux (모두 지원)
- **Python**: 3.8 이상
- **GPU**: NVIDIA RTX 3070 (8GB VRAM)
- **저장소**: 최소 30GB (모델 저장용)

### 네트워크
- 초기 모델 다운로드: 인터넷 필수 (1회)
- 운영 중: 불필요 (로컬 LLM 실행)
